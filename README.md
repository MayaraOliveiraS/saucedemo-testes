# 🧪 Testes Funcionais - SauceDemo

## Sobre o projeto

Projeto desenvolvido para praticar fundamentos de QA e testes funcionais utilizando a aplicação SauceDemo.

## Objetivo

Criar e executar casos de teste para validar funcionalidades principais da aplicação.

## Funcionalidades testadas

- Login
- Validação de login
- Adição de produto ao carrinho
- Remoção de produto do carrinho

## Casos de teste

- CT-001 - Login com credenciais válidas
- CT-002 - Login com senha inválida
- CT-003 - Login sem preencher os campos
- CT-004 - Adicionar produto ao carrinho
- CT-005 - Remover produto do carrinho

## Tipos de teste

- Teste funcional
- Teste positivo
- Teste negativo
